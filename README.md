#  Tienda Eureka - BackEnd API

API RESTful para la tienda en línea **Eureka**, diseñada para gestionar el catálogo de libros, autenticación de usuarios, carrito de compras, cupones de descuento, soporte al cliente y simulación de pagos.

Este backend está optimizado para integrarse con el frontend [Tienda.Eureka.FrontEnd](https://github.com/jorgediaz11/Tienda.Eureka.FrontEnd).

## 🚀 Tecnologías Utilizadas

- **Runtime:** Node.js
- **Lenguaje:** TypeScript
- **Framework:** Express
- **Base de Datos:** PostgreSQL
- **ORM:** Prisma
- **Autenticación:** JWT (JSON Web Tokens)
- **Seguridad:** Helmet, CORS, Express Rate Limit, Zod (Validación)

## 📋 Requisitos Previos

- Node.js (v18 o superior)
- PostgreSQL (v14 o superior)
- npm o yarn
